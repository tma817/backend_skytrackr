✈️ <h1>Welcome to SkyTrackR!</h1>

<p>SkyTrackR is your smart co-pilot for finding the best flight deals without the turbulence.
We combine Amadeus Flight API, AI-powered price prediction, and personalized recommendations to help you fly smarter — not harder.

💡 Whether you're planning ahead or chasing last-minute deals, SkyTrackR helps you:

🔍 Browse flights quickly
💸 Predict cheaper booking times using AI
🎯 Get personalized travel suggestions
🌎 Discover the best routes for your budget

Our mission?
Help travelers take off at the lowest price possible. 🚀</p>

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
